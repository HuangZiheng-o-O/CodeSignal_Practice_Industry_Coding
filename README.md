# CodeSignal Industry Coding Practice

这是一份按题型整理的 CodeSignal Industry Coding 练习资源导航。入口、题目说明、测试及参考代码的位置见 [题目导航.md](题目导航.md)。

本仓库通过 Git submodule 引用 25 个第三方 GitHub 仓库与 Gist，保留各自的原始来源和提交。它们是练习、复现或工程参考，不能视为 CodeSignal 官方题库。

## 获取全部练习资源

```bash
git clone --recurse-submodules https://github.com/HuangZiheng-o-O/CodeSignal_Practice_Industry_Coding.git
```

如果已克隆主仓库：

```bash
git submodule update --init --recursive
```

建议先做 `EricZheng0404__LibreSignal/Questions/in_memory_database/` 和 `Questions/bank_system/`，再用 `spartypkp__open-gauntlet/` 做完整计时练习。
